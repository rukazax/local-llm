# TeraTTSv2 на CPU: базовый замер (23.11.2026)

**RU** · [← README](../../README.md) · [09 · Книга и озвучка](../ru/09-books-writing-and-voicing.md)

Приёмка без Volta: качество озвучки не зависит от GPU, поэтому разборчивость, ударения и порядок RTF
сняты на CPU ещё до сборки стенда. Это базовая линия, к которой пристегнут VoxCPM2.

## Что запущено

| Параметр | Значение |
|---|---|
| Движок | **TeraTTSv2** (TeraSpace), ONNX Runtime 1.32, `CPUExecutionProvider`, threads=6 |
| Вес | 1,1 ГБ (`TeraSpace/TeraTTSv2`), скачан `hf download` |
| Стек | Python 3.14, transformers 5.24, torch 2.15.0+cpu (нужен только для `AutoModel`), num2words, numpy |
| Голоса | `ru_m5`, `ru_f1` (рекомендованные RU-промпты) |
| Хост | AI-NAS, 15 ГБ RAM, GPU нет |

- **RTF 0,34–0,67** на CPU: фраза в 4 с считается за ~1,5 с. Для рендера тома медленно (сутки на
  10 часов аудио), для приёмки и черновиков — годится.
- **RAM 2,5 ГБ** пикового RSS, загрузка модели 9,3 с.
- **WER 1,8 %** (1 слово из 57) по GigaAM (sherpa-onnx NeMo CTC int8, 16 кГц). Единственная ошибка
  морфологическая и на стороне ASR: сказано «сканирование», распознано «сканирования».

## Ударения

`normalize_text()` расставляет их до синтеза. На тестовой фразе:

```
В отс+еке ост+алось дв+адцать од+ин +ящик и с+орок дв+а конт+ейнера. Сен+я, ты чег+о з+амер?
```

Ошибок нет: отсЕке, остАлось, двАдцать, одИн, Ящик, сОрок, двА, контЕйнера, СЕня, чегО, зАмер.

## Чего этот замер не доказывает

- **VoxCPM2 не проверен**: нужен GPU (8 ГБ VRAM) и PyTorch-стек. Его тембр (SIM 81,1) и Voice
  Design остаются неподтверждёнными до Windows-бокса или Volta.
- **Эмоция не проверена**: `duration_scale` меняет темп, но не «злость»; у TeraTTSv2 эмоция — это
  выбор голоса, а не стилевая инструкция.
- **48 кГц нет**: выход 44,1 кГц — для мастеринга приемлемо, но это не VoxCPM2.
