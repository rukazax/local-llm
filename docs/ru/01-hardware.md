## Конфигурация (финальная)

| Компонент | Выбор | Почему |
|---|---|---|
| GPU | **4× Tesla V100 SXM2 32GB** | 128 ГБ HBM2 однородно; TP4 без компромиссов в любом движке |
| Несущая плата | база на 4 модуля с **полным NVLink** | NVLink 300 ГБ/с между картами; без него — вдвое медленнее (замер: 57 против ~100 ток/с на тех же картах) |
| Переходники | PCIe 3.0 x16 → 2× SFF-8654/8664 + 4 кабеля | хосту хватает x8: GPU↔GPU идёт по NVLink |
| Охлаждение | водоблоки + СЖО (360×45 + 240×30) | воздух не тянет 4×300 Вт; водоблок отводит ~300 Вт на карту |
| БП | 2 кВт, отдельная линия | простой ~200 Вт · нагрузка 700–800 Вт · пик 1350 Вт |
| RAM | **256 ГБ** DDR4-2400 RDIMM (8×32, два сокета, 8 каналов) | второй tier: эксперты MoE живут в RAM — [гибридный режим](06-hybrid-mode.md); эталон 1Cat-LLM ест ~62 ГБ host RAM |
| Диск | NVMe 4–8 ГБ/с | загрузка чекпойнтов 20–90 ГБ за минуты, не часы |
| Хост-ОС | Ubuntu 24.04+ | glibc ≥ 2.38, GLIBCXX ≥ 3.4.30 |

## BIOS/UEFI — обязательный чек-лист

1. UEFI boot, Legacy CSM выключен.
2. **Above 4G Decoding** — включить (без него карты не видны).
3. **Resizable BAR / Large BAR** — включить.
4. Если база в один слот — bifurcation x8/x8.

## Механика сборки (грабли сообщества)

- **Прижим SXM2**: все винты до упора, затем 16 центральных ровно на два полных оборота
  против часовой — это прижим контактов. После нагрузки проверять не только «линк активен»,
  но и счётчики ошибок NVLink (`nvidia-smi nvlink -e`) — в идеале нули.
- Комплекты пружин/шайб бывают неполными — пересчитать на каждую карту.
- Водоблоки: полная поверхность кристалла ровная, паста крестом, термопрокладки 5 мм на VRM;
  опрессовка контура 24 часа до запуска карт.
- Вентиляторы радиаторов — static-pressure (Arctic P12/P8), шум «газонокосилки» лечится большими
  медленными корпусными вентиляторами.
- Модули SXM2 не экономят энергию в простое: ~42 Вт на карту даже в idle.
- Лимит 250–300 Вт/карту (`nvidia-smi -pl`) почти не теряет производительности — и снижает пик со
  1350 Вт до ~1000.

## Риски

| Риск | Митигция |
|---|---|
| Ollama / upstream vLLM / PyTorch ушли с Volta | жить на llama.cpp + 1Cat; не строить на «умирающих» стеках |
| 1Cat-проект остановится | GGUF-очередь — страховка: те же модели на llama.cpp |
| Цены на V100 растут | докупать 32GB-модули сейчас, а не «потом» |
| NVLink ошибки под нагрузкой | счётчики ECC после каждого стресса; переустановка моста/платы при не-нулях |
| Питание/розетка | отдельная линия, ИБП на хост |
